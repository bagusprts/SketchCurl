# SketchCurl

Runs open-source machine learning experiments on a cluster of local computers with automatic task distribution.

SketchCurl is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Runs open-source machine learning experiments
- on a cluster of local
- computers with automatic task distribution

## Key Features

- Runs open-source machine learning experiments
- on a cluster of local
- computers with automatic task distribution

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchCurl.git`
2. `cd SketchCurl`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SketchCurl, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
